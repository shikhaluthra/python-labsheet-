# Student Academic Performance Analysis and Visualization

**Course:** BCA — Python Libraries and Applications  
**Project:** Student Academic Performance Analysis and Visualization Using Pandas and Matplotlib

This project analyzes student attendance, study hours, assignment/internal marks, subject marks, and final exam marks using **Pandas** and **Matplotlib**.

## Features
- Load and clean student data
- Calculate average marks and performance categories
- Identify high- and low-performing students
- Analyze subject-wise and department-wise performance
- Visualize attendance patterns
- Explore relationships between study hours, attendance, and marks

## Setup
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the analysis:
   ```bash
   python main.py
   ```

The program reads `data/students.csv` and saves charts in `outputs/`.

## Dataset
The included CSV is **sample/demo data** created for this project. Replace it with your actual student data if provided by your instructor. Keep the same column headers.
